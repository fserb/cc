2. A close that waits for the end of the turn (proposal 3)

nadya asks for the close once; cchost does it at the session's next turn end if nothing is typed and no draft is open. cc says so in the row's second line.

or, if you typed into it first:

3. Start a helper with its brief and its watch rules in one call (proposal 4)

Today nadya runs ccx new, a 20 s loop on /screen for the banner, ccx user "$(cat brief)", and two trig adds.

today (nadya's Bash, one helper)

ccx new --goal "cc tooling" ~/web/cc cc-b
for i in $(seq 1 10); do sleep 2; curl -s 127.0.0.1:7681/api/s/$pid/screen \
  | grep -q 'Claude Code v' && break; done
ccx user $pid "$(cat tmp/assign/cc-b.md)"
trig add 'on session.cc-b.done -> me "cc-b finished a turn: …"'
trig add 'on session.cc-b.asking -> me "cc-b asks: …"'
