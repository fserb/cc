Keys
  • ctrl k: the switcher over sessions, closed sessions, projects and recent files (the same fuzzy match the projects search uses).
  • alt ↓ / alt ↑: next / previous row of the sidebar.
  • alt w: the next session that waits on you (a dialog or a question), the rows cc draws with ?.
  • esc in the composer of a session: back to nadya.

Today the sidebar rows are not buttons or links (no tabindex anywhere in index.html; the accessibility tree lists them as plain text), so a keyboard user cannot reach them at all. Making each row a <a href="#pid"> fixes that on its own, before any shortcut.
